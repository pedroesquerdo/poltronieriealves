# Poltronieri & Alves

Site institucional da **Poltronieri & Alves Advogados Associados**, publicado como site estático no GitHub Pages.

## Produção

- Domínio: `https://poltronieriealves.com.br/`
- Branch de publicação: `main`
- Hospedagem: GitHub Pages
- Stack: HTML, CSS e JavaScript sem dependências de runtime

## Estrutura

- `index.html` — página principal, metadados sociais e dados estruturados
- `styles.css` — identidade visual e layout base
- `tweaks.css` — refinamentos visuais e responsivos
- `hero-ornament.css` — ornamento institucional do hero
- `script.js` — tema, menu mobile, animações e avaliações
- `robots.txt` — diretivas para mecanismos de busca
- `sitemap.xml` — sitemap do site
- `404.html` — página de erro personalizada
- `CNAME` — domínio personalizado do GitHub Pages
- `assets/` — arquivos oficiais de identidade visual

## Diretrizes

- Não recriar nem redesenhar os logotipos: utilizar somente os assets oficiais existentes.
- Manter caminhos compatíveis com GitHub Pages.
- Evitar dependências desnecessárias.
- Não inserir dados de clientes, avaliações, serviços ou credenciais que não tenham sido fornecidos e validados.

## Pendências externas ao código

Google Analytics, Google Search Console e eventuais políticas jurídicas/LGPD dependem de configurações, identificadores ou textos fornecidos pelo responsável pelo site.
